# Bunker Sounds

Personal offline sleep-sounds mixer built with Kotlin and Jetpack Compose.

Open this folder in Android Studio and run the `app` configuration on an emulator or connected Android device. The project includes generated color noises, digitally generated fan and air-conditioner sounds, bundled nature recordings, independent sliders, presets, effects, alarm support, a sleep timer, smooth sound transitions, favorites, saved scenes, sound information cards, backup/restore, and scheduled preset changes.

## Moving between Macs

Clone the repository, open it in Android Studio, and select the connected device or emulator. Android Studio will use the local SDK path on each Mac; `local.properties` is intentionally not tracked.
